# 2. Big picture

Một cách tổng hợp dễ học:

```text
Pattern 1 — ASSIST
Make people faster/better

Pattern 2 — CREATE & SYNTHESIZE
Turn information into useful output

Pattern 3 — ANALYZE & DECIDE
Turn data/context into insight

Pattern 4 — AUTOMATE & EXECUTE
Complete repeatable workflows/actions
```

Các pattern overlap.

Một workflow có thể dùng cả 4.

---

# 3. Pattern 1 — Assist and augment people

## Core idea

AI hoạt động như một **copilot/super-assistant** giúp human worker làm task nhanh hơn hoặc vượt qua skill bottleneck.

Examples:

- draft;
- edit;
- brainstorm;
- explain;
- prepare;
- translate;
- code assistance;
- meeting prep.

Mental model:

```text
Human expertise
+
AI assistance
=
higher speed / capacity / quality
```

---

# 4. Value mechanisms của Assist

## 4.1. Save time

Reduce repetitive effort.

## 4.2. Improve quality

AI acts as:

- reviewer;
- editor;
- second set of eyes.

## 4.3. Expand skills

User có thể làm task ngoài core specialty ở mức hỗ trợ.

## 4.4. Reduce friction

Các task “nhỏ nhưng phiền” trở nên dễ bắt đầu hơn.

---

# 5. Assist examples

### Engineering

```text
Developer
→ asks AI to explain unfamiliar code

→ human reviews/tests
```

Value:

- faster onboarding;
- faster debugging.

### Sales

```text
Sales rep

```

Value:

# 6. Metrics for Assist

- minutes saved;
- output quality;
- task completion rate;
- user satisfaction;
- throughput;
- time-to-first-draft.

Partner caution:

> Self-reported time saved hữu ích nhưng nên bổ sung operational metric khi có thể.

# 7. Pattern 2 — Create and synthesize

## Core idea

AI biến:

```text
Context / information
→ new useful artifact
```

Artifacts có thể là:

- text;
- code;
- image;
- report;
- brief;
- summary;
- translated/localized content;
- structured information.

---

# 8. Two directions

## Creation

```text
Goal + context
→ new output
```

Example:

> campaign draft.

## Synthesis

```text
Many inputs
→ condensed useful output
```

Example:

> summarize 100 customer comments into themes.

Hai hướng thường đi cùng nhau.

---

# 12. Pattern 3 — Analyze and support decisions

## Core idea

AI giúp chuyển:

```text
Data / documents / ambiguity
→ insight / explanation / options
```

Đây không có nghĩa:

> AI tự động là decision owner.

Nó có thể:

- inspect data;
- compare options;
- identify patterns;
- summarize evidence;
- generate scenarios;
- explain trade-offs.

# 16. Pattern 4 — Automate and execute workflows

## Core idea

AI không chỉ tạo answer.

Nó tham gia workflow:

```text
Observe
→ Reason
→ Use tools
→ Take permitted action
→ Verify
→ Escalate
```

Đây là pattern gần nhất với:

- automation;
- agentic workflows;
- execution.

---

# 17. Automation spectrum

Không phải automation luôn full autonomy.

## Level 1

```text
AI drafts
→ human acts
```

## Level 2

```text
AI prepares action
→ human approves
→ system executes
```

## Level 3

```text
AI executes low-risk cases
→ human handles exceptions
```

## Level 4

```text
AI executes broader workflow
with policy + monitoring + escalation
```

Điểm quan trọng:

> Degree of autonomy là design choice.

# 21. Map to OpenAI's official six primitives

OpenAI public business guide defines:

```text
1. Content creation
2. Research
3. Coding
4. Data analysis
5. Ideation & strategy
6. Automation
```

Một rough mapping để học:

| Official primitive | 4-pattern study framework |
|---|---|
| Content creation | Create & synthesize / Assist |
| Research | Create & synthesize / Analyze |
| Coding | Assist / Create / Automate |
| Data analysis | Analyze & decide |
| Ideation & strategy | Assist / Analyze |
| Automation | Automate & execute |

Không có mapping 1:1.

Điều này chứng minh:

> Pattern là lens, không phải rigid box.

---

# 22. OpenAI's three opportunity areas

Public use-case guide cũng khuyên tìm opportunity ở ba challenge:

1. **Repetitive low-value tasks**
2. **Skill bottlenecks**
3. **Navigating ambiguity**

Map:

```text
Repetitive tasks
→ Assist / Automate

Skill bottlenecks
→ Assist / Create / Analyze

Ambiguity
→ Research / Analyze / Ideation
```

Đây là một tool discovery rất tốt.

---

# 23. From primitive to workflow

Use-case primitive là atomic building block.

Business workflow có thể chain nhiều primitive.

Example — Marketing launch:

```text
Research
↓
Data analysis
↓
Ideation & strategy
↓
Content creation
↓
Automation
```

Business value thường xuất hiện lớn hơn khi primitives nối thành workflow.

# 24. From workflow to outcome

Đừng dừng ở:

> “AI can summarize.”

Hỏi:

```text
Summarize what?
For whom?
At which workflow step?
What happens next?
Which KPI moves?
```

Example:

```text
Summarize sales call
→ extract next steps
→ update CRM
→ draft follow-up
→ reduce admin time
→ improve follow-up speed
```

# 25. Pattern selection framework

Khi nhìn task, hỏi:

### Q1
Người dùng cần **làm nhanh/tốt hơn**?

→ Assist.

### Q2
Cần **tạo hoặc tổng hợp output**?

→ Create & synthesize.

### Q3
Cần **hiểu data / ambiguity**?

→ Analyze.

### Q4
Cần **workflow thực hiện action**?

→ Automate/execute.

Có thể chọn nhiều.

# 27. Example for a Frontend Developer

### Assist

AI explain unfamiliar React code.

### Create

# 29. Common mistakes

## Mistake 1 — Treat 4 patterns as official PartnerU taxonomy

Hiện chưa đủ source để khẳng định.

## Mistake 2 — One use case = one pattern

Workflow có thể combine.

## Mistake 3 — Automate everything

High-value solution có thể chỉ augment.

## Mistake 4 — Focus on capability instead of metric

“AI can create content” chưa nói được business value.

## Mistake 5 — Confuse output with outcome

Report được generate ≠ decision tốt hơn.
