# 04 — Common Productivity Workflows in ChatGPT

> **Course:** OpenAI Foundational Knowledge  
> **Course:** ChatGPT Essentials  
> **Section:** Common productivity workflows in ChatGPT

---

# 1. Section objective

Sau section này, bạn cần:

- nhận diện workflow productivity phổ biến;
- biết cách đi từ task đơn → multi-step workflow;
- dùng ChatGPT cho writing, research, analysis, meetings, data, planning và coding;
- biết output nào cần human verification.

---

# 2. Big picture

Productivity value thường đến từ:

```text
Input
→ understand
→ transform/analyze
→ create output
→ review
```

ChatGPT phù hợp nhất khi workflow có:

- language;
- information;
- analysis;
- creation;
- repeated knowledge work.

---

# 3. Workflow 1 — Writing

Common flow:

```text
Goal
→ outline
→ draft
→ critique
→ revise
→ final
```

Examples:

- email;
- memo;
- report;
- proposal;
- documentation.

---

# 4. Writing: better workflow

Instead of:

> Write this for me.

Use:

```text
1. Clarify audience.
2. Build outline.
3. Draft.
4. Review for gaps.
5. Rewrite.
```

This preserves human control.

---

# 5. Workflow 2 — Rewrite / editing

Use ChatGPT to:

- shorten;
- simplify;
- improve clarity;
- change tone;
- fix structure;
- translate/localize.

Example:

> Rewrite this update for executives. Keep factual content unchanged and reduce it to 150 words.

---

# 6. Workflow 3 — Summarization

Sources:

- document;
- meeting notes;
- article;
- transcript.

Possible outputs:

- key points;
- decisions;
- risks;
- actions;
- unanswered questions.

Good prompt:

> Summarize into decisions, owners, deadlines and open questions.

---

# 7. Workflow 4 — Research

Flow:

```text
Question
↓
plan
↓
search/current sources
↓
synthesize
↓
cite
↓
verify
```

Good for:

- market overview;
- current topic;
- vendor research;
- background research.

For current facts, use source-backed search/research capabilities.

---

# 8. Workflow 5 — Compare options

Provide criteria.

Example:

```text
Compare three approaches on:
- cost
- complexity
- risk
- time-to-value
```

Ask ChatGPT to distinguish:

- facts;
- assumptions;
- trade-offs.

---

# 9. Workflow 6 — Meeting preparation

Inputs:

- agenda;
- account notes;
- previous meeting;
- documents.

Output:

- briefing;
- goals;
- questions;
- risks.

Flow:

```text
Context
→ brief
→ questions
→ meeting
```

---

# 10. Workflow 7 — Meeting follow-up

```text
Transcript/notes
↓
summary
↓
decisions
↓
actions
↓
follow-up draft
```

Then user verifies:

- owner;
- date;
- commitment.

---

# 11. Workflow 8 — Brainstorming

Use ChatGPT to expand option space.

Good pattern:

```text
Generate
→ group
→ filter
→ compare
→ select
```

Avoid accepting first idea.

---

# 12. Workflow 9 — Planning

Examples:

- project plan;
- launch plan;
- study plan;
- migration plan.

Ask for:

- milestones;
- dependencies;
- risks;
- assumptions;
- next actions.

Plan is a draft for human judgment.

---

# 13. Workflow 10 — Document analysis

Upload source.

Ask:

- extract facts;
- compare versions;
- identify risks;
- find contradictions;
- answer questions from document.

For source-sensitive work:

> Tell ChatGPT not to add outside facts unless asked.

---

# 14. Workflow 11 — Spreadsheet/data analysis

Possible flow:

```text
Upload data
↓
inspect schema/quality
↓
define question
↓
analyze
↓
visualize
↓
explain
↓
validate
```

Use cases:

- trends;
- segmentation;
- variance;
- anomaly;
- summary.

---

# 15. Data analysis verification

Check:

- column definitions;
- missing data;
- filters;
- units;
- aggregation;
- assumptions.

A beautiful chart can still be based on wrong logic.

---

# 16. Workflow 12 — Coding support

ChatGPT can help:

- explain code;
- debug;
- create tests;
- review;
- prototype;
- document.

For larger repo workflows, specialized coding tools may be stronger.

---

# 17. Workflow 13 — Learning / explanation

Pattern:

```text
Explain
→ example
→ quiz
→ apply
```

Useful for new concepts.

Prompt:

> Explain at beginner level, then give one developer analogy and three self-check questions.

---

# 18. Workflow 14 — Translation/localization

Don't only ask:

> Translate.

Add:

- audience;
- tone;
- glossary;
- product terminology;
- locale.

Localization ≠ literal translation.

---

# 19. Workflow 15 — Information extraction

Turn text into fields.

Example:

```text
Customer email
→ issue
→ urgency
→ requested action
```

Structured format helps consistency.

---

# 20. Workflow 16 — Status reporting

Inputs:

- updates;
- metrics;
- blockers.

Output:

```text
Status
Progress
Risks
Decisions
Next steps
```

ChatGPT reduces synthesis effort.

---

# 21. Workflow 17 — Project-based ongoing work

Projects can store:

- files;
- chats;
- instructions;
- ongoing context.

Good for:

- recurring reports;
- long-term research;
- content projects;
- planning.

This avoids re-explaining background every chat.

---

# 22. Workflow 18 — Connected business context

With approved plugins/connections, ChatGPT can work with live business tools/data.

Example:

```text
CRM
+ docs
+ Slack
→ account/project synthesis
```

Permissions still apply.

---

# 23. Workflow 19 — Substantial work via Work

For bigger deliverables:

```text
Goal
→ gather info
→ analyze
→ create artifact
→ review
```

Current ChatGPT Work is designed for this larger execution pattern.

Examples:

- deck;
- document;
- spreadsheet;
- analysis;
- recurring update.

---

# 25. Pick the right tool

Task:

> Rewrite one paragraph.

Use:
Chat.

Task:

> Research a current topic with sources.

Use:
web/research capability.

Task:

> Analyze spreadsheet.

Use:
data analysis.

Task:

> Create a larger finished deliverable.

Use:
Work if available.

Task:

> Ongoing project context.

Use:
Project.

---

# 26. Workflow template

```text
GOAL
What outcome?

INPUT
What files/data/context?

PROCESS
What should ChatGPT do?

OUTPUT
What deliverable?

VERIFY
What must human check?
```

Mnemonic:

```text
GIPOV
```

Use only as study aid.

---

# 27. Example — Weekly project update

```text
Goal:
Leadership update.

Input:
Meeting notes + metrics.

Process:
Identify progress, blockers, decisions.

Output:
200-word status update.

Verify:
Dates, owners, metrics.
```

---

# 28. Example — Market research

```text
Goal:
Understand market.

Input:
Current web sources + company context.

Process:
Research → compare → synthesize.

Output:
Brief + source list.

Verify:
Source date, factual claims, assumptions.
```

---

# 29. Example — Data review

```text
Goal:
Explain revenue decline.

Input:
CSV.

Process:
Check quality → segment → compare → explain.

Output:
Table + narrative.

Verify:
Definitions + calculations.
```

---

# 30. Human review should match risk

Low-risk:

> brainstorm headline.

Light review.

Higher-risk:

> executive financial report.

Strong verification.

Rule:

```text
Higher consequence
→ stronger review
```

---

# 31. Common mistakes

1. Use ChatGPT only for Q&A.
2. Skip source/input context.
3. Ask for giant deliverable in one vague prompt.
4. No verification step.
5. Use Chat when task needs data tool.
6. Use manual repeated context instead of Projects.
7. Connect tools without considering permissions.
8. Measure productivity only by number of prompts.
