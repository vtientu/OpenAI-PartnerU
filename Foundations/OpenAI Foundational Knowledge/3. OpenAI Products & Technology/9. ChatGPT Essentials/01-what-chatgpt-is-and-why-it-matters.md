# 1. Section objective

Sau section này, bạn cần:

- giải thích ChatGPT là gì bằng ngôn ngữ đơn giản;

---

# 2. Big picture

OpenAI Academy hiện mô tả ChatGPT là một conversational AI assistant giúp người dùng:

- think;
- write;
- solve problems;
- work with natural language.

Một mental model tốt:

```text
User goal
↓
Natural-language interaction
↓
ChatGPT
├─ model reasoning
├─ files/images
├─ web/current information
├─ data analysis
├─ tools/plugins
└─ work execution
↓
Useful output / completed work
```

ChatGPT không chỉ là “chatbot hỏi đáp”.

Nó là một **general-purpose AI work surface**.

---

# 3. ChatGPT is a product, not just a model

Đây là distinction quan trọng.

## Model

Core AI capability.

## ChatGPT

Product experience built around model capabilities plus:

- conversation;
- files;
- tools;
- web;
- projects;
- workspaces;
- connected systems;
- other product features.

Therefore:

```text
ChatGPT ≠ LLM
ChatGPT ≠ one model
```

ChatGPT can evolve even when underlying model lineup changes.

---

# 4. ChatGPT vs OpenAI API

## ChatGPT

End-user product.

```text
Person
→ ChatGPT
→ result
```

Good for:

- direct productivity;
- research;
- analysis;
- writing;
- problem solving.

## API

Builder platform.

```text
Customer application
→ OpenAI API
→ AI capability
```

Good for:

- custom UX;
- embedded AI;
- product features;
- backend workflows.

A ChatGPT subscription does not automatically equal API usage.

---

# 5. Why ChatGPT matters

Traditional software usually requires user to learn:

- menus;
- commands;
- forms;
- workflows.

ChatGPT adds a natural-language interface:

```text
Intent
→ language
→ AI interprets
→ output/action
```

This lowers friction for many knowledge tasks.

---

# 6. ChatGPT as a general-purpose work assistant

Common work categories:

```text
Writing
Research
Analysis
Coding
Planning
Summarization
Brainstorming
Data work
Document work
Learning
```

One product surface can support many job functions.

This makes ChatGPT different from narrow software that solves one task only.

# 7. From asking to doing

A useful maturity progression:

```text
ASK
"What does this mean?"

↓
ASSIST
"Help me draft this."

↓
ANALYZE
"Compare these files."

↓
CREATE
"Turn this into a report."

↓
EXECUTE
"Use the available tools and complete this work."
```

Modern ChatGPT use increasingly extends beyond question answering.

---

# 8. Chat vs Work

OpenAI Academy currently frames:

## Chat

Best for:

- quick answer;
- explanation;
- brainstorm;
- rewrite;
- short draft.

## Work

Best for:

- larger task;
- clear finished artifact;
- multi-step work;
- longer-running execution.

Mental model:

```text
Chat
→ collaborate in conversation

Work
→ delegate a substantial unit of work
```

Exact availability depends on plan/workspace.

---

# 9. Input is more than text

A prompt can involve:

- text;
- image;
- audio;
- file.

Examples:

```text
PDF
→ summarize / compare

Screenshot
→ explain

Spreadsheet
→ analyze

Voice
→ discuss
```

This makes ChatGPT multimodal.

---

# 10. ChatGPT can use tools

Depending on plan/settings, tools can include capabilities such as:

- web search;
- data analysis;
- file handling;
- image creation;
- plugins/connections;
- work/agent capabilities.

Tool availability is dynamic.

Partner rule:

> **Describe the workflow first; verify exact feature availability second.**

---

# 11. ChatGPT can work with current information

A model's learned knowledge is not the same as current information.

ChatGPT may use web/search tools when available.

Concept:

```text
Model
+ current web source
→ fresher answer
```

For time-sensitive facts, users should prefer source-backed current information rather than relying on memory alone.

---

# 12. ChatGPT can work with user-provided context

Examples:

- document;
- spreadsheet;
- project instructions;
- conversation history;
- connected business content.

This lets ChatGPT adapt output to the task without retraining the model.

```text
Context
≠
model training
```

---

# 13. Why ChatGPT matters for employees

Potential value mechanisms:

- reduce blank-page effort;
- synthesize information;
- shorten research time;
- help with analysis;
- improve first drafts;
- support cross-skill tasks;
- reduce repetitive work.

Value is realized only when the workflow improves.

---

# 14. Why ChatGPT matters for organizations

Organization-level value requires more than individual usage.

Need:

- use-case discovery;
- training;
- workspace governance;
- safe data practices;
- shared workflows;
- measurement.

Progression:

```text
Individual use
↓
team best practices
↓
shared projects/workflows
↓
connected business context
↓
organization-scale adoption
```

---

# 15. ChatGPT is not a source of truth by default

ChatGPT can produce incorrect or unsupported outputs.

Do not assume:

> fluent = correct.

For important work:

- verify;
- ask for sources;
- use trusted documents;
- check calculations;
- apply domain expertise.

---

# 16. ChatGPT is not automatically connected to company systems

Without connection/tool:

```text
ChatGPT cannot simply know current CRM state
```

Need:

- plugin;
- connector;
- uploaded data;
- API/tool;
- user-provided context.

This distinction prevents overclaiming.

---

# 17. ChatGPT is not a replacement for business ownership

AI can help:

- analyze;
- draft;
- recommend;
- execute scoped work.

Humans/organizations still own:

- goals;
- permissions;
- policy;
- decisions;
- accountability.
